# Portafolio de Kevin Brown Herrera

Estudiante de Licenciatura en Química (Universidad de Panamá) y desarrollador backend.
Combino experiencia en laboratorio ambiental con programación: estos proyectos resuelven
problemas reales de un laboratorio con código probado.

| Proyecto | Qué demuestra |
|---|---|
| [01 - API de inventario de reactivos](01-inventario-reactivos-api) | API REST, base de datos, validaciones, pruebas |
| [02 - API de resultados de muestras](02-resultados-muestras-api) | Modelado de datos, lógica de negocio, códigos HTTP correctos |
| [03 - Reportes de laboratorio automatizados](03-reportes-laboratorio-automatizado) | Automatización de procesos, pandas, generación de Excel |

Todos incluyen pruebas automáticas (`python -m pytest -q`) y se ejecutan con
`pip install -r requirements.txt`.
